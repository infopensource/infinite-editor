# Infinite Editor 是怎么工作的

这份说明写给第一次使用编辑器的人，也给以后制作教程的人作参考。它描述的是现在程序真实会做的事。

## 你可以用哪两种方式编辑

编辑器有两个视图：

- **所见即所得**：直接看到标题、粗体、列表、表格、图片和公式的排版效果，点击文字就能编辑。
- **Markdown 源码**：直接编辑 Markdown 符号。打开预览后，左边是源码，右边是排版结果；也可以隐藏右边预览，专心写源码。

两种视图编辑的是同一篇文档。比如你在源码里加了粗体，切回所见即所得时会看到粗体效果；在所见即所得里改的内容，也会同步回源码。

切换视图时，编辑器会尽量保留光标位置和选中的文字。正在输入中文、日文等文字时，如果输入法还没有提交当前字，切换会暂时等一等，避免正在输入的字被截断。

所见即所得中的普通文字跨行选中时，高亮按每行的行高绘制，相邻行不会叠加颜色；正向、反向选择和页面缩放遵循同样的规则。包含图片、公式等独立内容的选区保留浏览器原生显示。

## 字数怎么计算

状态栏平时显示整篇文档的字数。用鼠标或键盘选中一段文字后，它会改为显示“字数：N（已选）”；点击别处取消选中后，又恢复整篇文档的字数。

这里的“字数”是看得见的内容：

- 空格、换行和 Markdown 的符号（例如 `**`、`[]()`）不算；
- 代码和公式里的内容会算；
- 图片按图片的替代文字计算；没有替代文字的图片不增加字数。

拖动鼠标选区时，编辑器会等选区稳定后再更新数字，所以不会因为每移动一个像素就重新计算整篇文档。源码视图只处理选中的源码片段；所见即所得视图只检查选中的内容。

## 输入、格式和撤销

- 普通输入会和两种视图同步。
- “开始”选项卡里的粗体、斜体、删除线、引用、项目符号、编号等命令，会作用于当前选中的文字或当前段落。
- “撤销”和“重做”在两个视图中共用同一条记录。你可以在源码视图输入，再切到所见即所得视图撤销，顺序不会丢。
- 工具栏命令执行完后，编辑器会重新获得焦点，通常可以继续输入。
- 格式命令在左键点击完成后执行，按下时保留正文选区；中键、右键不执行命令。用 Tab 聚焦按钮后，也可以按 Enter 或空格执行。

### 空格、换行和段落

编辑视图采用 Typora 默认编辑视图的空白处理方式，两种编辑模式遵循相同规则：

- 连续的普通空格会原样保存并按实际数量显示，不会折叠成一个空格。
- 同一段源码中的单个换行会保留显示，但仍属于同一个段落。
- 空行分隔两个段落。在所见即所得模式按 `Enter` 创建新段落，保存到源码时写成一个空行。
- 所见即所得模式按 `Shift+Enter` 插入段内硬换行，源码默认保存为“行尾两个空格 + 换行”。读取已有文档时仍兼容 `<br/>` 和反斜线硬换行，但再次编辑保存时会规范化为双空格写法。
- `Ctrl+Enter` 插入分页符；macOS 也可以使用 `Cmd+Enter`。
- 允许连续按 `Enter` 创建真正的空段落。为了避免 Markdown 解析器在模式切换、保存和重新打开时吞掉空段落，每个空段落保存为通用的 `&nbsp;` 占位行；它能被常见 Markdown 和 HTML 渲染器识别，不依赖 Infinite Editor 私有语法。
- 行尾两个或更多普通空格再接源码换行，会按 Markdown 规则产生段内硬换行。也可以直接写 `<br/>`。
- 为兼容已有文档，反斜线加换行仍可读作硬换行；下次从所见即所得模式保存时会规范化为行尾两个空格。
- 代码块中的空格与换行始终逐字保留，不受上述正文规则影响。

段内的自动折行、单换行和硬换行都使用正文行距；段落之间额外保留段后间距，因此按 `Enter` 创建的下一段能够和段内换行明显区分。

这套规则优先采用常见 Markdown 阅读器能够理解的源码：段内硬换行使用行尾两个空格，空段落使用 `&nbsp;`，不要求其他软件认识 Infinite Editor 私有标记。其他阅读器仍可能折叠正文中不位于行尾的连续空格。

## 分页和滚动

所见即所得视图会按照纸张大小显示页面，并在状态栏显示“第几页 / 共几页”。改变纸张、方向或边距，只改变显示方式，不会改动正文。

纸张宽高和页边距是强制约束，任何内容都不能撑大纸张或侵入页边距。单个表格单元格的文本超过一页时，必须按文字行跨页续排；同一表格行内各单元格同步分页，保持正文、格式和列宽。不能以保持表格行完整为由突破纸张尺寸，也不能通过隐藏或截断正文来满足限制。

Markdown 源码视图是连续的编辑区，不分页，也不会显示页码。双栏模式下，源码和预览会尽量保持相同的阅读位置。

工具栏里的“分页符”是正文中的一个明确标记。它会影响所见即所得视图的排版，但不会把源码编辑区变成分页编辑器。

## 图片、公式和其他内容

- 可以插入图片。桌面版从系统剪贴板粘贴图片时，会把图片保存到文档资源目录，再在正文中写入图片路径。
- 图片显示使用文档中的资源路径；仅仅打开或预览图片不会改写正文。
- 行内公式和独立公式都可以编辑，公式内容使用 LaTeX。
- 表格、列表、引用、链接、代码块和删除线会在两种视图之间保留。
- 编辑器遇到暂不支持直接编辑的 HTML 或指令时，会尽量保留原始内容，不会悄悄删掉。

## 打开、保存和导出

从“文件”页可以打开文档、保存修改、另存为或导出。打开文件时可以选择“只读”，打开后状态栏会显示这个状态；它目前主要是提示用途，真正禁止编辑的行为还需要后续完善。

保存为 Markdown 项目时，正文和布局信息分开保存；保存为 Infinite Document 时，正文、布局和资源可以打包在一起，方便移动或归档。导出为普通 Markdown 时，只导出正文，不包含页面布局设置。

打开另一篇文档后，上一份文档尚未完成的后台读取或渲染结果不会覆盖新文档。

## 状态栏还会显示什么

状态栏会显示当前提示、文件名、字数和当前视图。只有所见即所得视图显示页码；源码视图只显示与源码编辑有关的状态。

### 文档视图缩放

- 状态栏支持 50%–200% 缩放，滑块及加减按钮每次调整 10%；点击比例或“视图 → 100%”恢复默认。切换编辑模式保留当前会话比例。
- 采用 CSS `transform: scale()` 缩放编辑区，并反向补偿滚动视口宽高；页面、标尺和 Markdown 编辑/预览随之缩放，放大后可横向滚动。
- 缩放不修改文档、字体设置、撤销历史或导出尺寸。固定纸张保持原有分页；无缝模式及 Markdown 流式视图可随可用宽度换行。
- 缩放信号只订阅于状态栏，不使工作区因比例变化重新读取全文；通过 animation frame 合并选区和可见分页遮罩刷新，不启动固定纸张全文分页。
- 浏览器回归覆盖 50%、80%、100%、150%、200% 的选区、视口尺寸、分页遮罩、表格列宽，并断言缩放期间没有新增分页任务或编辑器事务。

- Ctrl/Cmd + 加号、减号调整文档缩放，Ctrl/Cmd + 0 恢复 100%；Ctrl + 滚轮、触控板捏合及 WebKit gesture 事件复用同一比例。捕获阶段阻止浏览器默认整页缩放，普通滚轮仍正常滚动；连续输入每帧最多同步一次状态栏。
