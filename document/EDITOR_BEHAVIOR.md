# Infinite Editor 是怎么工作的

这份说明写给第一次使用编辑器的人，也给以后制作教程的人作参考。它描述的是现在程序真实会做的事。

## 你可以用哪两种方式编辑

编辑器有两个视图：

- **所见即所得**：直接看到标题、粗体、列表、表格、图片和公式的排版效果，点击文字就能编辑。
- **Markdown 源码**：直接编辑 Markdown 符号。打开预览后，左边是源码，右边是排版结果；也可以隐藏右边预览，专心写源码。

两种视图编辑的是同一篇文档。比如你在源码里加了粗体，切回所见即所得时会看到粗体效果；在所见即所得里改的内容，也会同步回源码。

切换视图时，编辑器会尽量保留光标位置和选中的文字。正在输入中文、日文等文字时，如果输入法还没有提交当前字，切换会暂时等一等，避免正在输入的字被截断。

## 字数怎么计算

状态栏平时显示整篇文档的字数。用鼠标或键盘选中一段文字后，它会改为显示“字数：N（已选）”；点击别处取消选中后，又恢复整篇文档的字数。

这里的“字数”是看得见的内容：

- 空格、换行和 Markdown 的符号（例如 `**`、`[]()`）不算；
- 代码和公式里的内容会算；
- 图片按图片的替代文字计算；没有替代文字的图片不增加字数。

拖动鼠标选区时，编辑器会等选区稳定后再更新数字，所以不会因为每移动一个像素就重新计算整篇文档。源码视图只处理选中的源码片段；所见即所得视图只检查选中的内容。

## 输入、格式和撤销

- 普通输入会和两种视图同步。
- “开始”选项卡里的粗体、斜体、删除线、引用、项目符号、编号等命令，会作用于当前选中的文字或当前段落。
- “撤销”和“重做”在两个视图中共用同一条记录。你可以在源码视图输入，再切到所见即所得视图撤销，顺序不会丢。
- 工具栏命令执行完后，编辑器会重新获得焦点，通常可以继续输入。

## 分页和滚动

所见即所得视图会按照纸张大小显示页面，并在状态栏显示“第几页 / 共几页”。改变纸张、方向或边距，只改变显示方式，不会改动正文。

Markdown 源码视图是连续的编辑区，不分页，也不会显示页码。双栏模式下，源码和预览会尽量保持相同的阅读位置。

工具栏里的“分页符”是正文中的一个明确标记。它会影响所见即所得视图的排版，但不会把源码编辑区变成分页编辑器。

## 图片、公式和其他内容

- 可以插入图片。桌面版从系统剪贴板粘贴图片时，会把图片保存到文档资源目录，再在正文中写入图片路径。
- 图片显示使用文档中的资源路径；仅仅打开或预览图片不会改写正文。
- 行内公式和独立公式都可以编辑，公式内容使用 LaTeX。
- 表格、列表、引用、链接、代码块和删除线会在两种视图之间保留。
- 编辑器遇到暂不支持直接编辑的 HTML 或指令时，会尽量保留原始内容，不会悄悄删掉。

## 打开、保存和导出

从“文件”页可以打开文档、保存修改、另存为或导出。打开文件时可以选择“只读”，打开后状态栏会显示这个状态；它目前主要是提示用途，真正禁止编辑的行为还需要后续完善。

保存为 Markdown 项目时，正文和布局信息分开保存；保存为 Infinite Document 时，正文、布局和资源可以打包在一起，方便移动或归档。导出为普通 Markdown 时，只导出正文，不包含页面布局设置。

打开另一篇文档后，上一份文档尚未完成的后台读取或渲染结果不会覆盖新文档。

## 状态栏还会显示什么

状态栏会显示当前提示、文件名、字数和当前视图。只有所见即所得视图显示页码；源码视图只显示与源码编辑有关的状态。
