# 超长段落与 Markdown 分页专项测试

在编辑器中打开 `examples/long-paragraph-test.infdoc`，或者打开本目录的 `document.md`。包内包含相同正文、A4 页面设置和图片资源。综合测试文档已移除超长段落，仍保留长表格。

正文包含 14 类用例：纯文本长段落、混合格式与 Unicode、长词和 URL、软/硬换行、标题与分隔线、嵌套列表、任务列表、嵌套引用、代码块、行内数学/化学式、块公式与图片、长表格、宽表格/极高单元格、显式分页与原样保留语法。

检查方法：

- 切换 A4、A5、横向、自定义小纸张、无缝模式，再调整页边距。
- 检查页缝左右与纸张对齐，文字、引用竖线和代码背景不穿过页缝，表格列宽不因分页变化。
- 在跨页处输入、删除、选取文本、撤销/重做；保存后重开，确认段落、编号、表格行数和资源完整。
- 在所见即所得模式逐字输入 `**粗体**`、`*斜体*`、`***粗斜体***`、`~~删除线~~` 和反引号包围的行内代码；闭合后应立即转换。转换后直接按退格应恢复标记。代码内的星号、转义标记和未闭合标记应保留原文。
- 逐字输入 `$H_1=\liminf_{n\to\infty}(p_{n+1}-p_n)\le 186$`，闭合后应立即渲染；独立段落中的 `$$...$$` 转为块公式。代码里的美元符和转义美元符应保持原文。
- 第 13 节特意包含超过整页高度的单元格，用于暴露极端内容边界；不能只用普通短行表格替代此项检查。

自动回归：`npm run test:editor`。真实浏览器分页回归：`npm run test:pagination-browser`（需要 Chromium，可通过 `CHROMIUM` 指定路径）；该命令输出临时截图路径，并检查页缝宽度、文本遮挡、表格列宽、重排稳定性和无缝切换。

性能回归：`npm run test:pagination-performance`。使用本目录完整正文，在短段落和最长段落连续输入，检查任务取消、空闲/选区测量次数、源码视图编辑与模式往返一致性，并输出分阶段长任务和输入延迟。性能测试请单独运行，避免与其他测试争抢 CPU。架构、验收门槛和当前限制见 [性能契约](../../web/wysiwyg/PERFORMANCE.md)。
